# 🔐 Visual Cryptography System & Seminar Portal

An interactive web-based implementation of the **(2, 2) Visual Cryptography Scheme** originally proposed by Moni Naor and Adi Shamir (1994).

## ✨ Features
- **Interactive Scribbler Pad:** Draw freehand signatures or symbols and split them into encrypted shares.
- **Secret Text Generator:** Convert passwords, PINs, or messages into visual shares.
- **Image Encryptor:** Upload any image to threshold into binary and generate two random-noise shares.
- **Interactive Transparency Stacker:** Slide Share 2 horizontally over Share 1 to visually decrypt secrets without mathematical computation.
- **Seminar & Theory Guide:** Built-in presentation material covering history, pixel expansion math, real-world use cases, and trade-offs.

## 🛠️ Tech Stack
- **HTML5 Canvas** (Pixel manipulation & `multiply` transparency blending)
- **CSS3** (Responsive Grid & Dark UI)
- **Vanilla JavaScript** (Zero external dependencies)

## 🚀 Live Deployment (GitHub Pages)
1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to your GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, pick `main` / `/ (root)`, and click **Save**.
4. Your live website link will appear at the top of the Pages settings within 1–2 minutes.
